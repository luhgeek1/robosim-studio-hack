## Технический долг

- Локальный `make check` блокируется отсутствием `uv` в PATH; для правки 3D проверена сборка фронта.

- CI не настроен: ворота пока `make check` локально. Шаг: пайплайн SourceCraft после переезда (Q-010).
- В каталоге нет фото продуктов (`image_url` пуст) — взять из PDF-каталога организатора.
- G2P даёт 138 Ronavi M на 6 800 строк/ч: нормативы `g2p_robot_lines_per_trip` = 3 и `g2p_one_way_distance_m` = 40
  не откалиброваны — сверить с кейсом «Восток-Сервис» и имитацией. Сейчас отбор на G2P не окупается.
- Для `pick_assist` и манипуляторов нет модели N — в сценарий только с ручным количеством.
- Пик питания в больнице — через `hospital_peak_factor` на сутки; реальный пик — волны кормлений (18 отделений за час).
- Число курьерских обходов лаборатории оценено по «рейсам выдачи результатов» — других данных в датасете нет.
- Монте-Карло `surrogate` и `des` отвечают 409 — появятся с имитацией; заключение пока только по правилам (без LLM).
- НДС к вычету не моделируется: все суммы с НДС, в заключении есть оговорка с размером эффекта.
- Проверки на данных организатора: буксир Cognitive Pilot (3000 кг) исключается на перроне (нужно 3060 кг),
  ночной шум больницы 30 дБА исключит роботов с известным шумом (Доп. 5 разрешает допущение) — решить на ревью.
- `legacy/backend-v0/` удалить после переноса логики (до сдачи). Логи arq дублируются — выключить обработчик arq.
