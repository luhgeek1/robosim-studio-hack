## Что есть в репозитории

**Прототип v0** (коммит `cc2fdea`, автор luhgeek): около 3,5 тыс. строк TS и 2,4 тыс. строк Python. Доки прототипа — `docs/archive/`.

- **Работает:** импорт xlsx/csv/json/txt с нормализацией и происхождением параметров; валидация; подбор (жёсткие фильтры +
  взвешенный скоринг с объяснениями); расчёт количества; экономика «как сейчас / покупка / RaaS» с кривой на 60 месяцев;
  SimPy-симуляция очереди с зарядкой; рекомендация «минимальное N, при котором выполняется SLA»; 14 тестов pytest.
- **Не соответствует ТЗ или мок:**
  - визуализация трёхмерная, а не 2D, роботы двигаются случайно, планировка захардкожена;
  - нет авторизации и ролей, экспорта PDF/Excel, админки каталога, анализа чувствительности;
  - только склад; числовые ТТХ есть у 17 из 187 решений, их производительность — оценка команды;
  - SQLite без миграций.
- Готовность: ~65% для демо склада, ~40% относительно всего ТЗ.

**`template/`** — прошлый проект команды (FastAPI + Postgres + Alembic + JWT/RBAC, React FSD + shadcn + TanStack Query,
docker/nginx/caddy). Кандидат в основу нового каркаса.
