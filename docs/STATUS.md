  В каталоге организатора нет роботов-доставщиков внутри здания: доставка медикаментов и проб — «решений нет».
- Фронт скрывает полноту карточки и бейджи «Отечественный» / «Есть внедрения» в списках. Бэкенд это исправил
  23.09 (полнота — по общим ТТХ, `has_cases` — только при кейсах): можно вернуть (`CompletenessMeter` в
  `pages/catalog/parts.tsx`, `ProductBadges verifiedOnly`).

  на «Объекте» — 0 %. Решить на бэкенде, считать ли данные организатора подтверждёнными.
- Перебор флота: окупаемость точек (`points[].payback_years`) не совпадает с пересчитанным сценарием
  (демо: N = 8 — 3,4 года в таблице перебора, 1,7 года в сценарии). Проверить, на каких входах считаются точки.

- G2P: по циклу 155 роботов и 27 станций, по имитации 205 (узкое место — станции); `g2p_robot_lines_per_trip` = 3

- Планировка: хранение по ABC не моделируется; для аэропорта и больницы генератора нет (409).
