# РобоМера: Атлас возможностей

Авторская коммерческая концепция, основанная на заданной палитре и архитектурных макетах. Фотографии и фоторендеры исключены по брифу.

```css
--bg: oklch(0.949 0.016 85);
--surface: oklch(0.978 0.008 85);
--fg: oklch(0.232 0.012 155);
--muted: oklch(0.47 0.018 155);
--border: oklch(0.79 0.022 85);
--accent: oklch(0.640004 0.178829 36.145706);
--forest: oklch(0.291 0.038 162);
--font-display: 'Onest', 'Segoe UI', sans-serif;
--font-body: 'Onest', 'Segoe UI', sans-serif;
--font-mono: 'Onest', 'Segoe UI', sans-serif;
```

Акцент точно переведён из исходного #e35a34 в OKLch. Onest используется во всех ролях по прямому указанию пользователя.

- Широкий центрированный плакат вместо split-hero; архитектура занимает всю ширину.
- Терракотовый вступительный экран, бумажные содержательные разделы, один тёмно-зелёный разворот сравнения.
- Крупная типографика, асимметричный атлас, открытые структуры вместо одинаковых карточек.
- Скругления 4px у крупных панелей; 999px только у кнопок, табов и переключателей.
- Движение раскрывает устройство макета и изменение состояния; постоянного autoplay нет.
