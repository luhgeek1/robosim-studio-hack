# Исходники пространственного атласа

Самостоятельное направление создано в OpenDesign Cloud через Local Codex. Ведущий набор - `design-taste-frontend`, дополнения - `threejs` и `motion-lab`. Runtime находится в `../../public/design-lab/atlas/`.

- `src/world.js` - геометрия трёх объектов и элементы раскрытия.
- `src/atlas.js` - рендер, выбор объекта, реакция на указатель, пауза и запасной режим.
- `scripts/build.mjs` - локальные SVG из той же геометрии и сборка Three.js без CDN.
- `index.html` в runtime-каталоге - весь контент, стили и остальные взаимодействия.

Для пересборки геометрии: `npm ci`, затем `npm run build` из этого каталога. Зависимости изолированы от основного React-приложения. HTML не перезаписывается сборкой. Лицензии Three.js, Onest, Tabler и Motion Lab сохранены в runtime-каталоге `licenses/`.

После импорта ссылки адаптированы к нашему приложению, «Оценить свой объект» ведёт в `/demo?new=1`, добавлены возврат в галерею и режим без JavaScript. Изменения в репозитории и проекте OpenDesign Cloud автоматически не синхронизируются.
