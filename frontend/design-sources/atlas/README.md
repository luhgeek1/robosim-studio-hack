# Исходники пространственного атласа

Исходники экспериментального лендинга /design-lab/atlas/index.html.
Готовые ресурсы находятся в ../../public/design-lab/atlas.

Для пересборки выполните в этой папке npm ci, затем npm run build.
Сборка обновляет модели и JavaScript; HTML в папке готовых ресурсов сохраняется.
Зависимости изолированы от основного React-приложения. Лицензии сторонних ресурсов сохранены в папке licenses готового лендинга.
