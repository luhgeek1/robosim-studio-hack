# РобоМера: визуальный контракт

Источник: явные значения из задания. Система Linear используется как основа шкалы размеров, состояний и уровней поверхностей, но не как бренд.

```css
--bg: oklch(0.23098 0.01178 187.053); /* #171f1e */
--surface: oklch(0.26598 0.01178 187.053);
--fg: oklch(0.95671 0.01066 100.824); /* #f2f1e9 */
--muted: oklch(0.71722 0.01066 100.824);
--border: oklch(0.95671 0.01066 100.824 / 0.15);
--accent: oklch(0.68722 0.16402 37.876); /* #ed7049 */
--font-display: "Onest", "Segoe UI", sans-serif;
--font-body: "Onest", "Segoe UI", sans-serif;
--font-mono: "Onest", "Segoe UI", sans-serif;
```

- Один графитовый фон на всей странице. Поверхности различаются светлотой, без смены темы.
- Onest с кириллицей, локальные variable WOFF2. Три веса: 400, 510, 590. Числа поддерживают табличное выравнивание.
- Оранжевый используется для главного действия, маршрутов модели и клавиатурного фокуса. Других брендовых акцентов нет.
- Сохраняются название и существующий круглый знак-прицел из исходного LandingPage.tsx.
- Кнопки имеют радиус 6 px, внутренние элементы 4-6 px, крупные панели 12 px. Прозрачные границы и яркость поверхности обеспечивают глубину.

Итог: графитовая инженерная среда с ясной типографикой, тёплым мелом и оранжевым действием.
