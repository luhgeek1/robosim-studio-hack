# Исходники экспериментального лендинга

Страница /design-lab/system/index.html. HTML находится здесь, CSS и JavaScript — в src.
Сборка публикует файлы в ../../public/design-lab/system.

Команды из этой папки: npm ci, npm run build, npm run check, npm test.
Локальные шрифты, изображения и лицензии находятся рядом с готовым лендингом.

3D-сцена иллюстративная. Источник и дата чисел примера сохранены в evidence/warehouse-demo.json;
актуальные расчёты доступны в рабочем демо.
