# Продуктовая версия OpenDesign Cloud

Создана в OpenDesign Cloud через Local Codex. К проекту явно привязана система `linear-app`;
использованы Design Taste Frontend, Three.js и Design Review. Система адаптирована к графиту,
оранжевому и Onest РобоМеры. Это адаптация стороннего описания Linear, не официальный пакет Linear.

Runtime: `../../public/design-lab/system/`. Исходный HTML хранится здесь в `index.html`,
CSS и логика — в `src/`. Сборка обновляет runtime HTML, CSS и JS; статические шрифты,
отраслевые SVG и лицензии уже лежат в runtime. После клонирования: `npm ci`, `npm run build`,
`npm run check`, `npm test`. Runtime не требует Node или внешнего CDN.

Локальная адаптация: продуктовые ссылки переведены на относительные маршруты приложения,
добавлен возврат в галерею, сборка направлена в public. Генерация исходного проекта завершена
перед импортом. Изменения здесь не синхронизируются с OpenDesign Cloud автоматически.

Результат 17 → 13 — фиксированный подтверждённый пример склада, включая резерв.
Его источник и дата сохранены в `evidence/warehouse-demo.json`. Иллюстративная 3D-модель
не выполняет расчёт и не является точной планировкой этого склада. Для текущих чисел открывайте демо.

Проверки в основном проекте: Desktop 1440×900, mobile 390×844, переключение ракурса и фокуса
проверки, финансовые сценарии, меню, окно исходных данных, FAQ, reduced motion и режим без JS.
Локальные ресурсы и сборка проверены отдельно. Основной лендинг `/` не изменён.
