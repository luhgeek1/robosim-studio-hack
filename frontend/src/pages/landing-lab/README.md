# Варианты лендинга РобоМеры

Локальная галерея: `/design-lab`. Основной лендинг `/` не заменяется.

- `/design-lab/editorial` — React, Motion, собственная процедурная R3F-сцена. Числа берутся из публичного демо склада. Подтверждение показывается только для применённого парка с успешной совместной проверкой.
- `/design-lab/opendesign/index.html` — отдельный HTML, сгенерированный в OpenDesign Cloud через Local Codex и адаптированный для проекта. SVG-анимация объясняет принцип; численные результаты она не имитирует.

Запуск — обычный `npm run dev` из `frontend`. Для данных нужен backend по `VITE_PROXY_TARGET`; для чтения опубликованного демо при локальной проверке использовался `https://prooood.ru`.

## Происхождение

Первое направление использует рекомендации Web Design Studio (`cinematic-scroll`), Impeccable polish и Vercel Web Design Guidelines. Проверки Motion и R3F выполнены по документации Context7. Глобально установленные skills не являются runtime-зависимостями проекта.

Для второго направления использовались навыки `frontend-design`, `motion-lab` и `impeccable-design-polish` в OpenDesign Cloud. Локальная адаптация: относительные ссылки на приложение, WOFF2 из установленных Fontsource-пакетов, статичная SVG-разметка для режима без JavaScript и возврат в галерею. Лицензии шрифтов и Motion.Lab находятся рядом с артефактом.

Схемы созданы кодом, внешних GLB, текстур, фотографий и видеороликов нет. `warehouse-fallback.png` — кадр нашей сцены, полученный в браузере. Изображения `*-preview.png` — снимки готовых страниц.

## Проверка

`npm run check` проверяет TypeScript, lint, форматирование исходников и сборку. Автономный HTML дополнительно проверяется `npx prettier --check public/design-lab/opendesign/index.html`; его встроенный JavaScript проверен синтаксически и в браузере.

Браузерный проход: desktop 1440×900 и 1366×768, mobile 390×844, переключение данных и сцен, FAQ, клавиатура, reduced motion. Ошибка загрузки 3D не должна ломать первый лендинг. Его публичный запрос начинается после восстановления сессии, поскольку восстановление очищает общий Query-кэш.

Подробный отчёт и бриф поддерживаются в локальной документации проекта: `docs/DESIGN_TOOLKIT.md` и `docs/DESIGN_BRIEF_OPENDESIGN.md`. Эти файлы подчиняются существующему правилу `.gitignore` для `docs/`.
