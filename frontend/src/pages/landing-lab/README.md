# Экспериментальные лендинги

Галерея по адресу /design-lab сохраняет альтернативные варианты страницы. Основной сайт использует
отдельный лендинг; галерея не нужна для прохождения демо и расчёта роботизации.

React-варианты запускаются вместе с frontend. Статические варианты находятся в frontend/public/design-lab,
их исходники и команды сборки — в frontend/design-sources. Локальные лицензии лежат рядом с ресурсами.

Сцены лендингов иллюстративные. Для расчётов и результатов имитации используйте рабочие страницы проекта.
