# Пространственный лендинг

Экспериментальная страница /design-lab/immersive, запускается вместе с frontend.
Сцена Three.js иллюстрирует путь от объекта к оценке. Числа примера сохранены с источником
и датой в demo-snapshot.json; актуальные результаты доступны в рабочем демо.

ImmersiveStory связывает прокрутку и сцену, scene-state задаёт её состояния.
При уменьшении движения, недоступном WebGL или JavaScript используются локальные запасные изображения.
Проверки взаимодействий находятся в frontend/e2e. Основной лендинг и расчётное ядро от этой страницы не зависят.
