# РобоМера · Изнутри объекта - к решению

Самостоятельная версия `/design-lab/immersive`. Запуск из `frontend`: `npm install`, `npm run dev`.
Открыть http://localhost:5173/design-lab/immersive. Галерея `/design-lab` содержит новый вариант.
Production-проверка: `npm run check`, затем `npm run preview -- --port 5174`.
Основной маршрут `/` не меняется. Публикация этой версии не выполнялась.

## Постановка и движение

- Первый кадр: камера `[0, 2.35, 15]`, угол 50°, робот в проходе между высокими стеллажами,
  колонны и перекрытия продолжаются за экраном. Мягкая контактная тень связывает AMR с полом.
- На участке прогресса 0.10-0.64 камера поднимается; обрамляющая архитектура уходит,
  те же стеллажи и робот остаются. С 0.32 раскрывается маршрут. Средний ракурс смещён вправо,
  чтобы освободить место для пояснения связей и ограничений.
- На участке 0.64-0.94 камера центрирует склад, контейнер сцены уменьшается и занимает окно приложения.
  Интерфейс показывает параметры этого примера и проверенный состав парка. Это тот же Canvas.
  Заголовок решения проявляется на 0.76-0.88 и следует за закреплённой сценой, сохраняя отступ от рамки.
- История занимает 340svh. Обычная прокрутка - единственные часы, easing - smoothstep.
  Прогресс вычисляется из положения секции, поэтому обратный ход не зависит от истории кадров.
  Ни перехвата колеса, ни отдельного плавного скроллера нет.

`ImmersiveScene.tsx` - камера, свет, среда и обработка потери WebGL; `Warehouse.tsx` - геометрия,
инстансы коробок и стеллажей, маршрут. `RobotModel` переиспользован из Cinematic.
Сцена рендерится по требованию; DPR ограничен 1.5, карта тени 2048, локальная среда 128.
Сетевых HDR, 3D-моделей и новых npm-зависимостей нет.

До 760 px, при `prefers-reduced-motion`, ошибке WebGL или загрузке дольше 12 секунд:
три состояния складываются в обычную вертикальную страницу. Постеры сняты из этой же сцены.
Смена системной настройки движения обрабатывается без перезагрузки.
Vite добавляет для этого маршрута автономный noscript-вариант `static.html`.
При другом хостинге маршрут должен отдавать `dist/design-lab/immersive/index.html`;
соответствующее правило добавлено в конфигурацию галереи Vercel.

## Данные и границы

`demo-snapshot.json` - сокращённый снимок публичного
[демо склада](https://prooood.ru/api/v1/demo/projects/warehouse_demo_01), получен 20.10.2026,
подготовлен API 19.10.2026; сохранены revision, параметры, результаты и проверка парка.
Публичная копия - `/design-lab/immersive/evidence.json`.

Показаны 20 000 м², 17 роботов по формуле и 13 после имитации (11 рабочих + 2 резервных),
пять повторов проверки, экономика покупки/RaaS/лизинга. Числа относятся только к этому примеру.
Рядом раскрыты горизонт 5 лет и оптимистичное допущение о 100% денежной реализации труда.
Обновлять обе JSON-копии вместе; затем сверять числа в `ProductFrame` и автономном `static.html`.

3D - архитектурная иллюстрация механизма, а не точная планировка или воспроизведение журнала событий.
Это прямо подписано в интерфейсе. Точная имитация, входы и отчёт открываются в действующем продукте.
Новые расчётные функции не реализуются на лендинге. Все CTA ведут на абсолютные адреса `prooood.ru`.
