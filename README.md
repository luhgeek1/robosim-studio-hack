# RoboScope — прототип decision-support продукта для роботизации склада

Кликабельный frontend-прототип для хакатона. Помогает руководителю за несколько минут понять:
стоит ли роботизировать склад, какие роботы подходят, сколько их нужно, сколько это стоит
и справится ли конфигурация с реальной нагрузкой.

Без backend, API и реальных расчётов: всё на mock-данных проекта «Warehouse Moscow #01».

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173. Сборка: `npm run build`, предпросмотр сборки: `npm run preview`.

## Сценарий демонстрации

1. **Объект** — импортированные параметры склада, достоверность данных 91 %, обзорный 3D-двойник.
2. **Анализ** — нагрузка по часам, где ручной процесс не справляется, требования к решению.
3. **Роботы** — три решения с совместимостью, «почему подходит», риски, матрица критериев.
4. **Симуляция** — интерактивный digital twin: 2 / 3 / 4 робота, обычная нагрузка / пик,
   очередь на приёмке, подсветка узких мест, KPI, экономика, объяснение «почему 3».
   Кнопка «Показать демо-сценарий» проигрывает историю 3 → 2 → 3 робота автоматически.
5. **Экономика** — сценарии «Как сейчас» / «Покупка» / «RaaS», TCO, ROI, окупаемость,
   график выхода инвестиции в плюс.
6. **Решение** — итоговая рекомендация и следующие шаги; кнопки отчёта и экспорта — mock.

## Стек

Vite · React 19 · TypeScript · Tailwind CSS 4 · three.js через @react-three/fiber и drei ·
zustand · framer-motion · lucide-react.

## Структура

- `src/data/` — mock-данные: объект, каталог роботов и таблицы конфигураций, экономика сценариев.
- `src/twin/` — 3D-двойник: планировка, стеллажи, зоны, роботы-агенты и их маршруты.
- `src/sim/` — цикл, который плавно ведёт KPI к целевым значениям выбранной конфигурации.
- `src/screens/` — шесть экранов пользовательского пути.
- `src/components/` — общие элементы: кнопки, KPI с анимацией чисел, графики, панели.
