# RoboScope — прототип decision-support продукта для роботизации склада

Кликабельный frontend-прототип для хакатона. Помогает руководителю за несколько минут понять:
стоит ли роботизировать склад, какие роботы подходят, сколько их нужно, сколько это стоит
и справится ли конфигурация с реальной нагрузкой.

Frontend (этот каталог) + backend на FastAPI/SimPy (`backend/`). Все расчёты — подбор, количество,
экономика, симуляция — выполняет бэкенд; ML/LLM-часть — заготовка (`backend/app/ml/README.md`).
Статус и контекст проекта: `AGENTS.md`, `docs/STATUS.md`.

## Запуск

```bash
cd backend && python3 -m venv .venv && .venv/bin/pip install -r requirements.txt && .venv/bin/uvicorn app.main:app --port 8000
npm install && npm run dev     # в корне; http://localhost:5173, /api проксируется на бэкенд
```

Либо `docker compose up`. Сборка фронта: `npm run build`, предпросмотр: `npm run preview`.

## Сценарий демонстрации

0. **Проекты** — создание проекта, тип объекта, загрузка файла (xlsx/csv/json/txt) или демо-данные.
1. **Объект** — распознанные параметры, достоверность данных, правка значений с пересчётом, обзорный 3D-двойник.
2. **Анализ** — нагрузка по часам, где ручной процесс не справляется, требования к решению.
3. **Роботы** — три решения с совместимостью, «почему подходит», риски, матрица критериев.
4. **Симуляция** — интерактивный digital twin: 2 / 3 / 4 робота, обычная нагрузка / пик,
   очередь на приёмке, подсветка узких мест, KPI, экономика, объяснение «почему 3».
   Кнопка «Показать демо-сценарий» проигрывает историю 3 → 2 → 3 робота автоматически.
5. **Экономика** — сценарии «Как сейчас» / «Покупка» / «RaaS», TCO, ROI, окупаемость,
   график выхода инвестиции в плюс.
6. **Решение** — итоговая рекомендация, executive summary и следующие шаги; PDF — позже.

## Стек

Vite · React 19 · TypeScript · Tailwind CSS 4 · three.js через @react-three/fiber и drei ·
zustand · framer-motion · lucide-react.

## Структура

- `backend/` — API и расчётные движки (см. `backend/README.md`).
- `src/api.ts`, `src/query.ts` — клиент API и кэш запросов.
- `src/twin/` — 3D-двойник: планировка, стеллажи, зоны, роботы-агенты и их маршруты.
- `src/sim/` — цикл, который плавно ведёт KPI к результатам симуляции бэкенда.
- `src/screens/` — экран проектов и шесть экранов пользовательского пути.
- `src/components/` — общие элементы: кнопки, KPI с анимацией чисел, графики, панели.
