# Seed-датасет ТТХ складских роботов из каталога организатора

_Дата сбора: 2026-09-22. Файл данных: `warehouse_specs.yaml` (35 записей, 5 групп). Собрано за один сеанс с бюджетом ~80 обращений к сети; пробелы перечислены ниже._

## Зачем

В каталоге организатора (российские роботы, цены с НДС) нет структурированных ТТХ. Дополнение ТЗ требует обогащать характеристики из открытых
источников, и у каждого значения должны быть источник, дата получения и флаг подтверждения. Этот файл — стартовый набор для реестра допущений
и для загрузки в каталог платформы; числа не придумывались: если значения нет, стоит `status: missing`, `value: null`.

## Метод

1. Приоритет источников: страница продукта у вендора → официальный дилер/интегратор (КИИТ, RoboB2B, VVP Group) → пресса и кейсы → таблица
   организатора из `case/dataset` (для сверки).
2. Статусы: `confirmed` — страница/спецификация вендора; `claim` — дилер, пресса, кейс или таблица организатора; `inferred` — наш вывод
   (например, соответствие Cargo Unit платформе DH:FRAME, пересчёт А·ч → кВт·ч); `missing` — не найдено.
3. Каждое значение: `{value, unit, source, retrieved, status, note?}`. `retrieved` — дата открытия страницы (везде 2026-09-22).
   Если значение взято из сниппета поисковой выдачи, а страница не открывалась, это явно написано в `note` — такие значения перед
   использованием стоит перепроверить.
4. Порядок: группа A (AMR) → B (FMR/тягачи) → C (G2P/хранение) → D (комплектация/инвентаризация) → E (уборка). Файл писался инкрементально.
5. Дополнительные поля сверх заданной структуры: `vendor_url`, `registry_minpromtorg` (заявление о реестре Минпромторга/ПП 719/ГИСП),
   `commercial.price_rub` (цена вендора/дилера, чтобы сравнить с каталожной).

## Что заметили

**Вендоры без числовых ТТХ на сайте.** Дронсхаб (страница «грузовые мобильные роботы» — маркетинг, отдельной карточки Cargo Unit нет),
Семаргл (только линейка грузоподъёмности 50–2000 кг и тип навигации), Завод Стелкон (Pallet Shuttle «проектируется индивидуально»),
АРС SmartCube (только относительные эффекты «до x3 / до x4», высота шахт до 14 м), Сбер (роборука — нет продуктовой страницы),
Cognitive Pilot (сайт про агро; тягач описан только в прессе), МФТИ (комплект автономизации, без ТТХ). Сайт Яндекс Роботикс — SPA,
контент не читается при загрузке, значения взяты из сниппетов по домену вендора. Страница АК-SC80 у Автомакона отдала форму авторизации.

**Противоречия внутри источников.**
- Ronavi H1500: скорость 1,5 м/с (спецификация) против 1,3 м/с (кейс на том же сайте и RoboB2B); автономность «до 10 ч» (вендор) против 6 ч
  (таблица организатора) и 3–5 ч (RoboB2B); зарядка «~18 мин быстрая» против «1,3 ч полная».
- МОРОС AMR 100: 150 кг / 3 м/с на сайте вендора против 90 кг / 0,8 м/с у prommoscow.info (вероятно, старая ревизия). AMR 800: 2 м/с против 2,5 м/с.
- Waybot Cleanbotics 400 PRO: «до 2000 м²» на одной странице вендора и «до 4000 м²» на другой.
- РУБИ С: «до 2500 м²» за сеанс не сходится с 0,5 м²/с × 10 ч автономности.
- ДиКом DMR 1200/600: две карточки у дилера с разными ценами (4,25/4,0 и 3,75/3,4 млн).

**Каталожная цена против цены вендора.**
- Совпадают с верхней границей вендора: Ronavi H1500 (2,16–2,70), Ronavi M (1,785–2,40), Ronavi SR (0,60–0,95), DMR 600 (от 3,75), DMR Carrier P (4,30), AS-RS B (от 10,0).
- Расходятся: Ronavi H2000 — каталог 2,64 ниже минимума вендора 2,805; Ronavi SD — каталог 1,40 при цене вендора 0,36–0,40 (x3,5);
  Pallet Shuttle — 7,00 млн против ~28 000 EUR за шаттл (вероятно, с секцией стеллажа); робот-штабелёр RoboCV 2,50 выглядит заниженным
  для машины 1,4 т с подъёмом 7 м; MARK 2 SE 1,90 ниже дилерских 2,05–2,10. Все расхождения фиксировать в реестре допущений.

**RaaS / аренда (найдено).**
- Ronavi Robotics (`/pricing`): покупка, аренда (минимум 2 месяца, ПО и ТО включены, выкуп по остаточной стоимости) и «плата за действие»
  (минимальный контракт ~30 месяцев, зарядные станции/ТО/поддержка включены). Ставок нет — по запросу. На странице Ronavi M — «пилот, лизинг (RaaS) или покупка».
- Р2Б MARK 2 SE: аренда **от 100 000 ₽/мес** (интегратор, обучение, удалённая поддержка включены) — единственная опубликованная ставка в выборке.
- Evocargo: продаёт N1 как «Robots as a Service» под ключ, включая обслуживание; цифр нет.
- Остальные (МОРОС, ДиКом, Семаргл, RoboCV, СМ Роботикс, Waybot, РОБО, YaCuAi, Автомакон) аренду на сайте не предлагают или не публикуют.

**Реестр Минпромторга / ПП 719.** Явно заявлено только для ДиКом (DMR 600, DMR 1200, DMR 300 Rider — «Реестр российского оборудования,
сертификат Минпромторга», формулировка дилера КИИТ, номер записи не указан). Остальные вендоры пишут «российское производство»
(Ronavi, МОРОС, АРС, YaCuAi, Автомакон-инвентаризатор), но реестр не упоминают. Стоит проверить в ГИСП напрямую.

**Происхождение.** Все позиции — российские бренды; неясно происхождение шасси у Автомакон АК-2000-2 (индексы вроде XQC201E в линейке) и
АК-SC80 (индекс совпадает с OEM-поломойками Viggo/Chancee/ASTOR SC80), а также базовых машин RoboCV и МФТИ (retrofit серийных
штабелёров/тележек). Pallet Shuttle: стеллажи Стелкон, шаттл — импорт (Швеция, по сниппету). Cargo Unit и Evocargo N1 — уличная техника,
Cognitive Pilot — перронный тягач: для внутрискладского сценария они кандидаты только с оговорками.

**Полезные референсы с числами.** Восток-Сервис — 48 Ronavi H1500 + ~1000 мобильных стеллажей, комплектация x5, персонал −2…3 раза,
окупаемость 6 мес (вендор). X5 — 67 АК-2000-2 (таблица организатора). Пулково — 45 тягачей Cognitive Pilot (dp.ru; в других СМИ «до 45 к 2028»).
Evocargo — «более 50 внедрений». ВкусВилл Домодедово — первый AI Stock Counter 12M.

## Не закрыто (лимит ~80 обращений)

- **Клинботикс 600** — ни одного числового параметра; проверить https://robot.automacon.ru/cleanbotics600 и https://waybotrobotics.com.
- **АК-SC80** — страница не прочиталась; проверить https://robot.automacon.ru/cleaner и https://automacon.ru/cleaners/.
- **Яндекс Роботикс** (комплектовщик, инвентаризатор) — нужны страницы https://robotics.yandex.ru/g2p и /robotizatsiya-sklada в браузере (SPA).
- **Роборука Сбер** — публичных ТТХ нет; запросить у организатора.
- **Сёмабот, Pallet Shuttle, SmartCube, МФТИ, MULE** — нужны спецификации по запросу у вендора (габариты, скорость, АКБ).
- **Cargo Unit** — подтвердить у Дронсхаб, что это конфигурация DH:FRAME, и получить indoor-параметры.
- Не искали: шум, IP, срок службы и требования к полу по большинству позиций (вендоры их не публикуют) — закрывать допущениями.
